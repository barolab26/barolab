큰글씨 돋보기

작은 글씨를 화면으로 크게 보고, 필요한 순간만 정지해요.

정식 공개 출시 전입니다. 일반 설치 링크는 아직 안내하지 않습니다.

주요 기능

  • 기기 지원 배율과 조명 조절
  • 화면 정지 후 고대비 선택
  • 원하는 정지 화면만 직접 저장
  • 정지 사진을 확대하고 끌어서 살펴보기
  • 원본·고대비·흑백 반전 선택
  • 초점 맞추기와 사진 원래 크기 복귀
  • 선택 색상으로 사진 전체 저장: 화면에 보이는 일부만 잘라 저장하지 않습니다.

사용 전에 확인해 주세요

실시간 돋보기는 CAMERA 권한과 후면 카메라가 필요합니다. 권한을 거부하면 확대를 시작하지 않고 사용 안내와 권한 설정을 제공합니다. 마이크·사진첩 전체 접근 권한은 요구하지 않습니다. 화면 정지·백그라운드 이동 때 카메라와 조명을 해제합니다. 회전 중 정지 화면은 메모리에 유지하지만 앱 프로세스가 종료되면 사라질 수 있습니다.

v3에서는 앱 실행 시 Google 광고·동의 SDK를 시작하고 필요한 동의 확인 후 카메라 첫 화면 하단에 배너 광고를 요청합니다. 카메라 조작 버튼과 배너 사이에 10dp 여백을 둡니다. 사용 안내 화면에서도 광고 표시를 선택할 수 있습니다. 카메라 영상과 정지 이미지는 광고 요청에 넣지 않습니다. v3 릴리스는 SJ AdMob 실제 광고 설정을 사용합니다. 광고 노출은 동의 상태·네트워크·광고 공급에 따라 달라지며, 광고가 표시되지 않아도 핵심 기능을 사용할 수 있습니다. 이전 v2 내부 테스트에는 Google 테스트 광고가 적용되어 있습니다.
