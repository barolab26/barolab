1. 기기에서 처리하는 정보

카메라 영상과 정지 화면은 기기의 메모리에서만 처리합니다. 얼굴 인식·OCR·원격 이미지 분석·클립보드·자동 촬영·업로드를 하지 않습니다. 앱 내부에 영상·정지 이미지 파일을 자동 저장하지 않으며 지속 설정도 보관하지 않습니다.

계정 가입과 별도의 앱 사용 분석·크래시 분석 SDK는 없습니다. 자체 측정 백엔드도 없습니다. 기기 백업·기기 이전에는 앱 데이터를 포함하지 않도록 설정합니다. 운영자가 앱의 로컬 내용을 원격 조회하지 않습니다.

2. 권한과 기기·외부 제공자

실시간 돋보기는 CAMERA 권한과 후면 카메라가 필요합니다. 권한을 거부하면 확대를 시작하지 않고 사용 안내와 권한 설정을 제공합니다. 마이크·사진첩 전체 접근 권한은 요구하지 않습니다. 화면 정지·백그라운드 이동 때 카메라와 조명을 해제합니다. 회전 중 정지 화면은 메모리에 유지하지만 앱 프로세스가 종료되면 사라질 수 있습니다.

3. 공유·저장

정지 화면 저장 버튼을 누르면 Android 문서 선택 화면에서 위치를 고릅니다. 취소하면 저장하지 않습니다. 화면에 보이는 장면을 긴 변 최대 2048픽셀의 PNG로 저장하며 선택한 고대비를 반영합니다. 사용자 선택 위치가 클라우드 파일 제공자이면 그 제공자의 통신·보관 정책이 적용됩니다. 앱이 자동 업로드하지 않습니다.

4. 광고와 동의 SDK

v3에서는 앱 실행 시 Google 광고·동의 SDK를 시작하고 필요한 동의 확인 후 카메라 첫 화면 하단에 배너 광고를 요청합니다. 카메라 조작 버튼과 배너 사이에 10dp 여백을 둡니다. 사용 안내 화면에서도 광고 표시를 선택할 수 있습니다. 카메라 영상과 정지 이미지는 광고 요청에 넣지 않습니다. v3 릴리스는 SJ AdMob 실제 광고 설정을 사용합니다. 광고 노출은 동의 상태·네트워크·광고 공급에 따라 달라지며, 광고가 표시되지 않아도 핵심 기능을 사용할 수 있습니다. 이전 v2 내부 테스트에는 Google 테스트 광고가 적용되어 있습니다.

Google Mobile Ads SDK와 User Messaging Platform(UMP)을 사용합니다. 비맞춤 광고를 요청하며 필요한 지역의 동의 절차와 광고 요청 가능 여부를 확인합니다. 광고 개인정보 선택 양식이 필요한 경우 앱의 광고 개인정보 선택에서 다시 열 수 있습니다. 동의·광고 처리가 실패해도 핵심 기능을 사용할 수 있습니다.

NPA(비맞춤 광고) 요청은 데이터 수집이 없다는 뜻이 아닙니다. Google SDK는 IP 주소와 이를 통한 대략적 위치, 기기 또는 기타 식별자, 앱·광고 상호작용, 진단·성능 정보를 광고 제공·측정·부정 이용 방지 등을 위해 수집·공유할 수 있습니다. SDK 전송은 TLS 보호를 따릅니다. 이전 테스트 버전과 실광고 릴리스 구성은 구분합니다.

카드 문구·보내는 이 이름·장보기 항목·카메라 영상·음성 내용을 광고 요청 매개변수·관심 분류·콘텐츠 URL로 넣지 않습니다. 광고 SDK의 보관·삭제는 Google의 정책과 기기 설정에 따르며 운영자가 Google 기록을 일괄 삭제한다고 보장하지 않습니다.

  • Google SDK 데이터 공개
  • Google 개인정보처리방침
  • Google 광고 기술 안내

5. 개인정보 삭제 요청 방법과 보관

메모리의 정지 화면은 실시간 보기로 돌아가거나 앱 프로세스가 종료되면 유지되지 않습니다. 사용자가 저장한 PNG는 파일 앱 또는 선택한 저장 제공자에서 직접 삭제해야 합니다. 앱 제거가 사용자 저장 파일의 삭제를 뜻하지 않습니다.

운영자에게 보낸 문의 메일도 삭제 요청 대상입니다. 문의 이메일 주소와 내용은 답변·후속 처리에 필요한 동안 메일 서비스에 보관합니다. 고정된 자동 삭제 기한을 약속하지 않습니다.

  1. 삭제 요청 메일 쓰기 또는 baro76650@gmail.com 으로 보내 주세요.
  2. 제목은 큰글씨 돋보기 개인정보 삭제 요청으로 적어 주세요.
  3. 대상 문의 메일의 시기·제목·발신 주소 등 찾는 데 필요한 최소한의 내용만 적어 주세요. 비밀번호·주민등록번호·불필요한 건강/민감 정보는 보내지 마세요.
  4. 운영자가 확인 가능한 범위와 삭제 가능한 내용을 확인한 뒤 회신합니다. 제3자 SDK·음성 제공자·공유 상대의 사본은 해당 제공자의 절차를 안내하며 일괄 삭제를 보장하지 않습니다.

기기 데이터와 사용자가 외부에 저장·공유한 사본은 서로 다릅니다. 문의 메일 삭제가 기기 데이터를 삭제하지 않고 앱 제거가 Google 또는 다른 제공자의 기록 삭제를 뜻하지 않습니다. 삭제 요청 메일 자체는 대상 확인·처리 결과 회신에 필요한 동안 사용합니다.
