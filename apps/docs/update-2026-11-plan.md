# 앱 4종 업데이트 설계서 (2026-11-17)

헤드 Claude Code 작성. 구현은 Codex와 나누고, 제미나이 웹이 리뷰한다. 수정 범위는 `apps/` 안으로 한정한다(대표님 지시).

## 왜 하는가

- 목적은 AdMob 광고 수익이고, 그 전제는 스토어 검색으로 설치가 일어나고 다시 열게 되는 것이다.
- 가족 테스터 의견(대표님 전달, 2026-11-17)
  - 시니어는 안부·말씀 카드를 서로 공유하는 것을 좋아한다. 고급스럽고 예쁜 배경이 더 많았으면 좋겠다.
  - 사용하기 더 편했으면 좋겠다.
  - 성경 앱의 읽어 주는 목소리가 듣기 불편하다. Google AI Studio의 자연스러운 성우 음성으로 바꾸고, 듣기 편한 목소리를 고를 수 있게 해 달라.
- 대표님 지시: 단점은 없애고 장점은 키운다. 고급스럽게, 쓰기 편하게, 시니어가 공유하기 편하게.

## 공통 원칙

- 새 화면·새 권한·새 광고 형식을 만들지 않는다. 광고는 배너만 유지한다(세 모델 합의).
- 글씨는 지금보다 작아지지 않는다. 주요 버튼 글씨는 18sp 이상, 누르는 영역은 56dp 이상.
- 기존 사용자의 저장 데이터(초안, 즐겨찾기, 목록, 테마 번호)는 그대로 열려야 한다.
- 바꾼 동작마다 단위 테스트를 하나씩 둔다(순수 자바 로직에 한해).
- 버전: 일상 3종 0.4.0(코드 4), 성경 0.6.0(코드 6).

## 1. 오늘의 안부 (가장 먼저 힘을 싣는 앱)

장점: 매일 보낼 이유가 있고 공유로 스스로 퍼진다. 문구 60개, 편집·저장·공유가 된다.
단점: 배경이 9개뿐이고 사진 배경은 3개. '오늘의 카드'가 날짜가 바뀌어도 그대로다. 공유까지 가는 길이 길다.

바꿀 것
1. 고급 사진 배경을 9개 더한다(사진 배경 3 → 12). 기존 테마 번호 0~8은 그대로 두고 9~17을 뒤에 붙인다. 리소스 이름은 `card_photo_10` … `card_photo_18`이 아니라 주제 이름으로 한다(아래 목록). 파일은 헤드가 만들어 `greeting/src/main/res/drawable-nodpi/`에 넣는다(1080×1350, WebP).
   - `card_photo_peony`(작약), `card_photo_plum`(매화), `card_photo_lotus`(연꽃), `card_photo_cherry`(벚꽃길), `card_photo_rose`(장미 정원), `card_photo_maple`(단풍길), `card_photo_pine_snow`(눈 내린 소나무), `card_photo_sunrise`(산 해돋이), `card_photo_tea`(찻잔과 창가)
   - 기존 PNG 3장도 같은 크기의 WebP로 바꿔 앱 용량을 줄인다(이름 유지).
2. 배경 고르기를 이름 목록이 아니라 작은 그림(썸네일) 격자로 보여 준다. 사진 배경을 앞에 둔다.
3. '오늘의 카드'는 날짜로 정한다. 날짜가 바뀌면 오늘 추천 문구와 배경이 바뀐다. 쓰던 초안은 지우지 않고 '이어서 쓰기'로 따로 남긴다. 앱으로 돌아왔을 때(onResume) 날짜가 바뀌었으면 갱신한다.
4. 첫 화면에서 한 번만 눌러 오늘의 카드를 바로 공유할 수 있게 큰 '보내기' 버튼을 둔다(지금의 공유 기능을 그대로 호출).
5. 공유·저장하는 카드 그림 맨 아래에 아주 작게 '오늘의 안부' 앱 이름을 넣는다(받은 사람이 앱을 알게 되는 유일한 고리, 리뷰어 지적). 글씨를 가리지 않는 위치와 크기로 한다. 스토어 주소 문구는 프로덕션 출시 뒤 업데이트에서 붙인다(지금은 테스터만 열 수 있는 주소).

## 2. 오늘의 성경말씀

장점: 매일 알림으로 다시 열게 된다. 큰 글씨, 듣기, 카드 공유가 있다.
단점: 구절이 30개뿐이라 한 달이면 반복된다. 기기 기본 음성이 듣기 불편하다. 알림을 눌렀는데 전에 읽던 구절이 열릴 수 있다.

바꿀 것
1. 낭독을 미리 녹음한 성우 음성으로 바꾼다. 구절마다 목소리 2종(차분한 여성, 따뜻한 남성)의 음성 파일을 앱에 넣고, 설정에서 고른다. 파일은 헤드가 Google AI Studio 음성으로 만들어 `bible/app/src/main/assets/voice/<목소리>/<구절 id>.ogg`에 넣는다. 파일이 없는 구절은 지금의 기기 음성으로 읽는다(기능이 사라지면 안 된다). 음성은 모노 32~48kbps로 압축하고, 보통 대화보다 조금 느린 속도로 만든다. 옛 맞춤법을 잘못 읽지 않았는지 만든 음성을 다시 글로 받아 적어 본문과 대조한다. 성경 카드에도 아주 작은 앱 이름을 넣는다.
2. 알림을 누르면 언제나 오늘 구절이 열린다.
3. 구절을 30개에서 60개로 늘린다(리뷰어 의견: 음성 파일 때문에 앱 용량이 커지므로 60개까지만). 출처는 지금과 같은 eBible 개역한글 1910(퍼블릭 도메인)이고, 본문은 원문과 글자 하나까지 같아야 한다. `content/verses.json`, `content/source-manifest.json`을 같은 형식으로 채운다. (헤드가 구절 목록과 원문 대조를 맡는다.)
4. 말씀 카드 배경에 안부 앱과 같은 고급 사진 배경을 쓴다(잔잔한 것 6장을 골라 넣는다).

## 3. 큰글씨 돋보기

장점: 급할 때 바로 쓴다. 확대·조명·정지·저장이 다 된다.
단점: 카메라 화면에 배너가 떠서 급한 조작을 방해할 수 있고, 스토어 설명('도움말에만 광고')과 다르다. 버튼 글씨가 15sp로 작다.

바꿀 것
1. 카메라 화면의 배너를 없애고 도움말 화면에만 둔다(스토어 설명과 일치).
2. 버튼 글씨를 18sp 이상으로 키운다.

## 4. 말로 장보기

장점: 넷 중 완성도가 가장 높다. 음성·키보드 입력, 되돌리기, 지난 목록 다시 쓰기.
단점: 음성 버튼이 3개로 나뉘어 처음 보면 무엇을 눌러야 할지 헷갈릴 수 있다.

바꿀 것
1. 첫 화면에서 가장 큰 버튼 하나('말로 추가')가 바로 눈에 들어오게 한다. 나머지 음성 선택은 작은 글씨로 두지 않고 설정 안으로 옮긴다(리뷰어 지적: 작은 글씨는 공통 원칙 위반·오조작). 동작(미리 보기 후 확인)은 그대로 둔다.

## 5. 스토어 검색 노출

- 앱 이름(30자), 짧은 설명(80자), 긴 설명을 5060이 실제로 검색하는 말에 맞춘다. 경쟁 앱의 검색어를 조사해 정한다(헤드).
- 스토어 화면 사진은 새 배경과 새 기능이 보이게 다시 찍는다.

## 하지 않는 것

- 전면·앱 오프닝·보상형 광고, 로그인, 서버, 새 권한.
- 안부 앱의 아침 알림(리뷰어 제안)은 새 권한이 필요해 이번에는 넣지 않고 다음 업데이트 후보로 둔다.
- 이미 올린 테스트 버전의 스토어 설명과 다른 동작.
