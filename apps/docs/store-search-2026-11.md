읽는 법
- 안부·성경은 찾는 사람이 많다. 돋보기는 '확대경'이라는 말이 같이 쓰인다. 장보기는 찾는 사람 자체가 적다.
- 요일·계절 인사말(월요일인사말, 가을인사말 등)을 찾는 사람이 꾸준하다. 안부 앱에 요일별·계절별 인사 문구를 넣으면 검색과 매일 다시 열 이유가 함께 생긴다(다음 업데이트 후보).

지킬 것
- 앱에 없는 기능을 이름·설명에 쓰지 않는다. '편안한 목소리'는 성우 음성이 들어간 버전을 올린 뒤에 반영한다.
- 리뷰어가 낸 이름 후보(추정)는 실측과 다른 부분이 있어 위 표로 대체했다: '카톡 안부 카드'·'큰글씨 성경'·'읽어주는 성경'·'장보기 메모'는 찾는 사람이 적었다.
- 긴 설명 첫 문단에도 위의 많이 찾는 말을 한 번씩 자연스럽게 넣는다. 같은 말을 되풀이해 채우지 않는다.
