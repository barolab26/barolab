오늘의 안부

마음에 맞는 문구를 고르고, 직접 고쳐 카드로 나눠요.

정식 공개 출시 전입니다. 일반 설치 링크는 아직 안내하지 않습니다.

주요 기능

  • 문구와 보내는 이 이름을 직접 확인하고 수정
  • 테마·글씨·대비를 바꾸고 미리보기
  • 즐겨찾기와 사용자 선택 이미지 저장·공유
  • 관계·상황에 맞는 문구 후보 3개에서 고르기
  • 별도 편집 화면에서 수정한 뒤 적용 또는 취소
  • 기존 도형 배경 6가지와 새 원작 사진 배경 3가지
  • 기존 저장 카드의 배경 선택을 유지하는 즐겨찾기

사용 전에 확인해 주세요

입력한 이름이나 문구를 앱 서버로 전송하거나 생성 모델에 보내지 않습니다. 회원가입과 연락처 조회 없이 사용합니다.

v3에서는 첫 화면, 문구 모음, 내 카드 목록 하단에 배너 광고를 요청합니다. 카드 편집 화면에서는 배너를 숨기며 조작 영역과 광고 사이에 여백을 둡니다. 전면·보상형 광고는 없습니다. v3 릴리스는 SJ AdMob 실제 광고 설정을 사용합니다. 광고 노출은 동의 상태·네트워크·광고 공급에 따라 달라지며, 광고가 표시되지 않아도 핵심 기능을 사용할 수 있습니다. 이전 v2 내부 테스트에는 Google 테스트 광고가 적용되어 있습니다.
