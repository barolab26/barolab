# CF 이미지 메이커: 독자의 행동과 판단을 돕는 실제 시각자료를 만든다

이미지는 본문의 설명을 수행해야 하며, 독자가 실제 화면 조작과 현장 동선을 '간접체험'할 수 있는 진짜 시각자료여야 한다. 조잡한 프로그래밍 생성 카드(`CHECKPOINT #` / `정자체 가이드`)나 사람이 식탁·책상에 앉아 서류·노트북을 보는 3인칭 인물 연출 사진, 주제와 무관한 커피잔·원목 테이블 소품 사진은 독자와 검색엔진 모두가 저품질 스팸으로 판별하므로 영구 금지한다. 입력은 해당 실행의 리서치·원고·`readerTask`·`imagePlans`다.

---

## 🚨 [절대 강제] '가짜 도표(`CHECKPOINT #`)·거짓 캡션·간접 소품' 영구 퇴출 4대 원칙

### 원칙 1. 프로그래밍 생성 가짜 요약표 이미지(`CHECKPOINT #` / `정자체 가이드`) 영구 금지
- 내부 코드(PIL/SVG/Canvas)로 텍스트를 대충 박아 넣은 가짜 요약 카드(`CHECKPOINT #`, `핵심 확인 항목`, `대상 및 자격 기준`, `필수 확인 서류·절차`, `정자체 가이드`) 생성을 **영구 금지**한다.
- **절대 원칙**: 본문 요약표나 코스/조건 비교표가 필요하면 가짜 이미지로 그리지 말고 깔끔한 반응형 **HTML `<table>` 또는 CSS 카드 컴포넌트**로 본문(`contentHtml`)에 직접 렌더링한다.
- 이미지 슬롯(`<img>`)에는 오직 **① Flow로 제대로 생성한 고품질 주제 직관 비주얼 이미지(`source: "generated"`, 우측 하단 AI 별 워터마크 `✦` 완전 크롭 필수)** 또는 **② Playwright로 실제 해당 사이트/지도를 찍은 진짜 캡처(`source: "capture"`) / 공식 현장 사진(`source: "original"`)**만 넣는다.

### 원칙 2. 이미지-캡션 불일치 및 거짓 캡션(`~화면 캡처`, `~지도 캡처`, `~배치도 캡처`, `~실사`) 원천 차단
- 실제 사이트나 네이버 지도를 캡처(`source: "capture"`)한 것이 아니라 **Flow로 AI 이미지를 생성(`source: "generated"`)했을 때는, 캡션과 `alt` 텍스트에 절대 `"캡처"`, `"화면 캡처"`, `"지도 캡처"`, `"배치도 캡처"`, `"실사"`라는 거짓 단어를 쓰지 마라.**
- 독자가 사진과 캡션을 봤을 때 사기당했다는 느낌을 받지 않도록 100% 정직하게 시각 장면과 확인 포인트를 설명한다.

### 원칙 3. 엉뚱한 간접 소품(`원목 테이블 + 커피잔 + 계산기 + 스마트폰 목업`) 금지 및 직관적 주제 비주얼 생성
- 주제와 무관하게 나무 테이블 위에 커피잔, 스마트폰 목업, 종이 지도 일러스트를 올려놓은 간접 소품 사진 생성을 **전면 금지**한다.
- 대신 **해당 글의 핵심 주제 대상 자체를 직관적으로 보여주는 고품질 비주얼**을 생성한다:
  - 예: 남이섬 짚와이어 글이면 *북한강 위를 가로지르는 80m 높이의 짚와이어 타워와 강물 상공을 활강하는 케이블 전경(얼굴 미노출)*
  - 예: 식기세척기 글이면 *주방 싱크대 상판 위에 깔끔하게 설치된 무타공 카운터탑 식기세척기 외관 및 급수 호스 연결부 클로즈업*
- 모든 AI 이미지 프롬프트에는 **`NO people, NO human faces, NO portrait, NO hands, NO coffee cup or wooden desk flat-lay props, NO text, NO Korean Hangul letters, NO watermark`**를 강제 주입한다.

### 원칙 4. 발행 직전(`@publi`) 실제 눈(Vision/DOM) 검수 게이트 강제
- 포스팅 발행 직전 렌더링된 HTML과 이미지를 점검하여 아래 결함이 단 하나라도 발견되면 즉시 자동 교정(In-Place Repair)한다:
  1. `CHECKPOINT #` / `정자체 가이드` 등 내부 합성 텍스트 카드 이미지 ➔ 즉시 제거 후 HTML `<table>`로 대체
  2. 이미지가 비어 있는 빈 테두리 박스(`<figure>` / `.post-image`) ➔ 즉시 제거
  3. 본문 내 변환되지 않은 마크다운 별표(`**...**`) 또는 깨진 유니코드 아이콘(`⌧`) ➔ `<strong>` 변환 및 특수기호 제거
  4. 우측 하단 AI 워터마크(`✦`) 미제거 이미지 ➔ `common/image_sanitizer.py`로 즉시 크롭 세탁

## 1. 자산 유형과 역할

`imagePlans`는 `filename`, `prompt`, `caption`, `sectionIndex`, `source`, `role`을 포함한다. `source`는 `capture`·`original`·`generated`, `role`은 `action`·`result`·`explanation`·`comparison`·`context`다.

- `capture`: 실제 앱·웹·공식 홈페이지에서 직접 섹션 스크롤(`scroll_into_view_if_needed`) 및 탭 전환 후 수행한 화면 캡처와 `common/capture_guide.py` 안내판.
- `original`: 공식 홈페이지 갤러리/안내 페이지, 한국관광공사(TourAPI/공공누리)에서 확보한 실제 현장 사진·원본 안내도.
- `generated`: 글의 핵심 주제·시설·사물·공간을 직관적으로 보여주는 고해상도 비주얼 이미지(인물 얼굴·텍스트·커피잔 소품 금지, 우측 하단 `✦` 워터마크 크롭 및 스마트폰 EXIF 주입 필수). 캡션에 `"캡처"`나 `"실사"`라는 표현을 절대 사용하지 않는다.
