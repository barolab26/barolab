# CF 문체: 독자의 질문에서 해결까지

이 문서는 CF 웹사이트 글의 문체 기준이다. 네이버 계정별 감상 문체·고정 인사·가운데 정렬·해시태그 양식을 옮겨 적용하지 않는다.

첫 문단에서 짧은 답과 적용 범위를 알려준다. 문제 상황을 길게 공감하는 도입 대신 독자가 고를 경로와 필요한 준비를 먼저 제시한다. 제목은 실제로 해결하는 질문과 범위를 담으며 과장된 불안이나 호기심으로 클릭을 유도하지 않는다.

짧고 자연스러운 존댓말로, 한 문단에 한 가지 행동이나 판단을 담는다. 메뉴명·버튼명·입력값·정상 결과는 구체적으로 쓴다. `기록을 확인하세요`보다는 `변경된 셀을 우클릭하고 수정 기록 표시를 선택하세요. 팝업에서 변경 시각과 이전 값을 확인할 수 있습니다`처럼 쓴다. 실제 메뉴와 표현은 직접 확인한 환경에 맞춘다.

화면이 필요한 곳은 행동 설명 가까이에 실제 캡처를 붙인다. 캡션은 화면에서 찾을 위치와 읽을 결과를 설명한다. 마지막에는 해결됐는지 확인할 방법을 남긴다. 감상·안부·감사 인사는 내용과 무관하면 넣지 않는다. 글자 수·소제목 수·이미지 장수는 정해진 합격 기준이 아니다.

사용자경험은 문제 → 시도 → 막힌 지점 → 바꾼 행동 → 관측 결과로 표현한다. 실제 수행하지 않은 업무·구매·사용 경험은 만들지 않는다. 테스트 문서에서 재현했다면 테스트 범위를 밝힌다. 예시·가정·계산·직접 관찰을 구분하며 독자에게 필요 없는 내부 승인 절차나 제작 로그를 본문에 나열하지 않는다.

비교는 독자가 선택할 조건과 예를, 계산은 입력과 결과를, 설명은 적용 가능한 구체예를 중심으로 쓴다. 출처는 기능·조건·변경 정보를 확인하거나 다음 행동으로 이동하는 데 도움이 될 때 가까이 연결한다. 출처 설명이 사용법을 대신하지 않도록 한다.


## 독자 맞춤 신규 작성 기준 — 2026-10-23

이는 원고 작성 지침이며 발행을 중단하는 검수 게이트가 아니다. 도메인의 실제 카테고리에 맞추고, 새로운 수익·피크 주장을 만들어내지 않는다.

- 연금·복지·시니어 건강(baronote.kr, must-good.com, smilenote.kr): 대상 / 확인할 조건 / 다음 행동을 세 줄로 먼저 안내한다. 다정한 존댓말, 굵은 소제목, 읽기 쉬운 요약 박스와 공식 자료 기반 3열 이내 비교표를 쓴다. 모바일 가로 스크롤·인라인 표 스타일은 기존 공용 조립기를 사용한다.
- 직장인 실무(soulnote.kr, maxnote.kr, topnote.kr, justinfo.co.kr): 결론 / 주의점 / 바로 할 일을 세 줄로 먼저 준다. 준비물·절차·예외를 짧게 설명해 출퇴근·점심시간에 핵심을 읽을 수 있게 한다.
- 가전·살림(must-pick.com, daynote.kr, meganote.kr): 적합한 사용자와 사용 조건을 먼저 제시하고, 확인된 규격·유지비만 비교한다. 없는 체험·가격을 만들지 않는다.
- 여행·문화(tripmarvel.com, nolplace.com, must-joy.com), 반려동물(joynote.kr), 주거(woorinote.kr), 건강(healthcox.com): 현재 질문에 대한 짧은 결론과 대상별 선택 조건을 앞세운다. 의료·법률·지원금 조건은 수집한 근거 범위를 지킨다.
- 시간대는 dashboard/data/daily_schedule.json의 사용자 지정 실험 정책을 참조하고, 실제 CF 실행 시간은 dashboard/data/cf/daily_schedule.json을 사용한다. 이미 발행된 슬롯의 시간을 바꾸거나 지연된 글을 다음날로 미뤄 당일 목표에서 빼지 않는다.
- @trace의 URL별 실측 결과가 없으면 전략 가중치를 성과 점수로 올리지 않는다. 기존 문서·예약·로그를 보존하고 다음 신규 원고부터 적용한다.
