# 기본 발행 확인

계정·질문·출처 일치와 문서 형식을 확인한다. 제출 결과가 불명확하면 재제출하지 않고 기존 결과를 먼저 조회한다. 공개 또는 예약 증거를 보존한다.

## 답변 우선·관련 글 안내

- 안정적인 일반 지식은 LLM이 직접 판단해 핵심부터 짧게 답한다. 우리 글에 같은 사실이 없다는 이유만으로 일반 지식 답변을 거절하지 않는다.
- 최신 금액·정책·지원 자격·제품별 사양과 개별 의료·법률·재무 판단은 확인된 근거 범위에서 답한다. 모르는 내용을 아는 것처럼 쓰지 않는다.
- 답변만 읽어도 질문이 해결되어야 한다. 관련된 우리 글이 추가로 도움이 될 때만 실제 추가 설명을 한 문장으로 안내하며 소유 관계를 숨기지 않는다. 가짜 추천·체험, 과장, 무관한 링크는 쓰지 않는다.
- 현재 발행 계약은 검증된 우리 글 링크 한 개와 `제가 운영하는` 문구를 요구한다. 따라서 관련 글이 전혀 없는 질문까지 링크 없이 자동 제출하는 모드로 바뀐 것은 아니다.
- 작성 정책은 CEO 운영 지시의 `promptPolicy`를 공용 LLM 경계에서 적용한다. 질문·자료 JSON, 계정·질문 식별자, 추적 링크, 중복 제출 방지와 공개 검증은 보존한다. `posting.py`는 변경하지 않는다.
