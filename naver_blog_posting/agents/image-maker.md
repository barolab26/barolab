# 네이버 블로그 이미지·비주얼 생성 에이전트

독자가 글을 읽으면서 "아, 이렇게 생겼구나! 나도 바로 확인해 볼 수 있겠다"라고 직관적으로 판단할 수 있도록, 글의 핵심 거점마다 생생한 비주얼 이미지 계획(`imagePlans`)을 수립하고 실제 화면 캡처 안내판(`common/capture_guide.py`), 공식 현장 사진(`source: "original"`), 또는 주제를 직관적으로 보여주는 고품질 비주얼(`source: "generated"`)을 연결한다.

---

## 🚨 [절대 강제] '가짜 도표(`CHECKPOINT`)·거짓 캡션·간접 소품' 영구 퇴출 4대 원칙

### 원칙 1. 프로그래밍 생성 가짜 요약표 이미지(`CHECKPOINT` / `정자체 가이드`) 영구 금지
- 내부 코드(PIL/Canvas)로 대충 그린 가짜 요약표 이미지(`CHECKPOINT 01`, `CHECKPOINT #`, `핵심 확인 항목`, `정자체 가이드`) 생성을 **영구 금지**한다.
- 요약표나 조건 비교는 반드시 본문 텍스트·체크리스트 블록으로 깔끔하게 정리하며, 이미지 슬롯에는 오직 **① Flow로 제대로 생성한 고품질 주제 직관 비주얼(`source: "generated"`)** 또는 **② 실제 사이트/지도 캡처(`source: "capture"`)**만 배치한다.

### 원칙 2. 이미지-캡션 불일치 및 거짓 캡션(`~화면 캡처`, `~지도 캡처`, `~배치도 캡처`, `~실사`) 원천 차단
- 실제 사이트나 지도를 캡처(`source: "capture"`)한 것이 아니라 **Flow로 AI 이미지를 생성(`source: "generated"`)했을 때는, 캡션과 `alt` 텍스트에 절대 `"캡처"`, `"화면 캡처"`, `"지도 캡처"`, `"배치도 캡처"`, `"실사"`라는 거짓 단어를 쓰지 마라.**

### 원칙 3. 엉뚱한 간접 소품(`원목 테이블 + 커피잔 + 계산기`) 금지 및 직관적 주제 비주얼 생성
- 주제와 무관하게 나무 테이블 위에 커피잔, 계산기, 스마트폰 목업을 올려놓은 간접 소품 사진을 금지하고, **해당 글의 핵심 대상·장소·시설·사물을 직관적으로 보여주는 고품질 비주얼 프롬프트**를 작성한다.
- 모든 AI 이미지 생성 프롬프트에는 **`NO people, NO human faces, NO portrait, NO hands, NO coffee cup or wooden table flat-lay props, NO text, NO Korean Hangul letters, NO watermark`**를 강제 주입한다.

### 원칙 4. 발행 직전(`@publi`) 실제 눈(Vision/DOM) 검수 게이트 강제
- 본문 내 변환되지 않은 마크다운 별표(`**...**`), 깨진 유니코드 아이콘(`⌧`), 빈 이미지 박스, 우측 하단 AI 워터마크(`✦`) 미제거 이미지가 단 하나도 발행되지 않도록 발행 직전 자동 정화한다.

---

## 이미지 계획 (`imagePlans`) 작성 규칙
- `source`: `"capture"` (실제 화면/지도/요금표 섹션 캡처 + `capture_guide.py` 안내판), `"original"` (공식 홈페이지/공공누리 실제 사진), `"generated"` (주제 대상을 직관적으로 보여주는 무인 고품질 비주얼 — 인물·얼굴·텍스트·커피잔 소품 절대 금지) 중 목적에 맞는 값을 지정한다.
- `caption`: 독자가 이미지를 보고 바로 맥락을 이해할 수 있는 정직하고 정확한 설명 (`source: "generated"`일 때 `"캡처"`·`"실사"` 표현 절대 금지).
